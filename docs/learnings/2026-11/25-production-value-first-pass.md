## 2026-11-25: Production value, first pass: a game opens on your people; place names are plain geography; the game can fill the screen

- **What happened.** The designer asked what else would raise production value. A review of master found the big moments (era takeover, war declared, victory) already read as premium and the minute-to-minute did not: a new game went from the lobby straight into turn 1, the map lettered a historical game with invented fantasy names ("Frostmarch", "The Ashen Waste", "The Drowned India"), and the game always sat under the browser's tabs. Sound is the largest gap (one track cut into two loops, no ambience, silent map animations); it follows in its own change.
- **The people's introduction** (`celebrate/PeopleIntro.tsx`). A new game opens on a full-screen plate in the era takeover's language: the first era's painting, the leaders' portrait, name and motto, then the faction sheet's own strengths, prices and goal (same strings, so it cannot drift from the sheet). `store.introSeats` lists the local seats still owed it; `startGame` sets every human seat of this browser and joining an online game on its first turn with no orders yet sets seat 0, never a load. One primary, Begin; Return and Esc both close it, except while a dialog is open above it (How to Play, opened from its "Full rules in How to Play" link, keeps its own Esc).
- **Gotcha: a held plate at game start breaks every scripted play-through.** Hundreds of e2e tests press Start game and expect turn 1. `e2e/fixtures.ts` therefore sets `legatum.intro.v1 = off` before each page loads (only when the key is unset), and `e2e/tour/people-intro.spec.ts` sets it to `on`. The hosted smoke test (`e2e-hosted`) has no fixtures and presses Begin as a player would. A new test harness that starts games needs one or the other.
- **Place names** (`map/labels.ts::placeName`). A name is where the place lies (the map ninth: "Northern", "South-Eastern", or the middle's own list) and what it is ("Sea", "Desert", "Steppe"). Cells that share a ninth take the list in grid order, so a name does not change as more of the map is explored; the game's salt only turns the list. The ninth is taken from the middle of the cell, otherwise a 4-cell-wide map puts four cells in each corner ninth and the corner names repeat.
- **Full screen needs Esc.** In full screen a browser takes Esc to leave it before the page sees the key, and Esc is the game's Close. The setting is offered only where the Keyboard Lock API can keep Esc for the game (Chromium); elsewhere the row is hidden (`platform/display.ts::fullscreenSupported`). For the same reason the installed app's manifest asks for `standalone`, not `fullscreen`.
- **Install.** `public/manifest.webmanifest` plus 192 and 512 px icons (`tools/design/app-icon/build.mjs`) make the site installable; Settings shows "Install Legatum" only after the browser has fired `beforeinstallprompt`, so the button never does nothing. No service worker: the versioned deploys (a game finishes on the build it started on) must not be cached behind one.
- **Not done here.** The introduction uses the Ancient era's painting for every people (Switzerland stands before a ziggurat); a painting per people is art work. Narration plugs in at `data-people` when the voice samples are chosen.
